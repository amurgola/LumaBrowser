A Site API turns a signed-in persisted tab into named endpoints: record the steps once in a builder chat, then call them with parameters from chat, from MCP clients as siteapi_* tools, or over /api/site-apis.
Every validated endpoint is a siteapi_<site>_<endpoint> tool. The site_apis tools list sites, run any endpoint by name (drafts included) and bring a site's tab to the front when it needs a sign-in.
