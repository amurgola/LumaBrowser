Tasks are created and managed in the Timed Tasks panel, opened from the clock button in the toolbar. Each task runs its prompt on a schedule, stores every run, and can POST the result to a webhook.

Runs use the AI Chat Navigator model. Change it in the AI Chat settings (Extensions, AI Chat, Configure).
The chat agent can list, create, run, pause, and delete timed tasks through the timed_tasks tools. Creating or deleting a task from chat asks for approval first.
