# LumaBrowser features

The [README](../../README.md) says what LumaBrowser is and how to start. These
pages say what each part does, in full.

| Page | What it covers |
|---|---|
| [Browser](browser.md) | Tabs, privacy, Chrome extensions, the password manager, the search palette, the Dashboard and the Hub |
| [Local models](local-models.md) | Runtimes, fitting a model to your GPUs, drafters, the helper model, per-model settings, model testing, the local API |
| [Images, video, music and voice](media.md) | The image, video, music and speech models, CivitAI, image editing, the media viewer |
| [Agents and coding](agents.md) | Chat tools, agents, Code mode, Tool Forge, Site APIs, Roleplay, and connecting outside agents over MCP, ACP, WebDriver and CDP |
| [Computer use](computer-use.md) | Desktop control, the built-in terminal, window tabs, the docked Lumabyte panel, system-wide hotkeys, the Desktop Integration API |
| [Automation and triggers](automation.md) | Notification and network forwarding, page watches, recurring tasks, triggers, ntfy |
| [Sharing](sharing.md) | Network Sharing between your devices, the web app, live tab sharing |

What changed in each release is in the
[release notes](https://github.com/amurgola/LumaBrowser/releases). The file by
file developer docs start at [Documentation/index.md](../index.md).
