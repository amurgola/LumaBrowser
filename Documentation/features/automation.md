# Automation and triggers

Turn what happens in the browser into webhooks, notifications and agent runs.

## Watching the browser

- Forward web notifications from any tab to a webhook.
- Watch a page, or one element on it, and get a notification or webhook when
  it changes.
- Capture network responses matching a URL pattern and forward them.

## Recurring tasks

Recurring AI tasks with an optional response schema and a result webhook.

## Triggers

Start an agent run from:

- an incoming webhook (Slack and GitHub presets),
- a file or folder change,
- a notification,
- a page change.

Each trigger has filters, cooldowns and quiet hours. A trigger or timed task
warns when its run will use state-changing or desktop tools without asking.
