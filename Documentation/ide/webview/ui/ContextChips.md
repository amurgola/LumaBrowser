# ContextChips

`ide/webview/ui/ContextChips.js`

The context chips above the composer, each with a remove button that asks the host to drop it.

## Methods

- `new ContextChips(container, host)`; `paint(items)`.
- `ContextChips.label(item)`: `path`, `path:12` or `path:12-30`; `selection` without a path.
