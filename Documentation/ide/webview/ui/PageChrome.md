# PageChrome

`ide/webview/ui/PageChrome.js`

Repaints what follows the session state: header, connection dot, send/stop buttons, placeholder, hint and hero.

## Methods

- `new PageChrome(el, page)`; `paint()`.
- `PageChrome.placeholder(state)`, `PageChrome.connClass(state)`, `PageChrome.metaText(state)`.
