# ProjectOverviewTool

`extensions/code-mode/tools/project/ProjectOverviewTool.js`

`project_overview {}` (a [CodeTool](../CodeTool.md)).

## Behaviour

From `context.code.projectMap`: `Project root`, `Files: N[+ (capped)]`, up to 8
types, 12 top-level folders, entrypoints, manifests and readme, one per line.
Summary: `N[+] files · <top 3 types>`.
