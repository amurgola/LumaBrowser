# ui/dock

`extensions/desktop-integration/features/lumabyte/ui/dock.html`

The 36 px button in an attached window's corner: navy glass, hairline rim,
ember underglow and the Luma mark, springing in on attach. Its rim lights while
the panel is open and runs the island's comet while a reply is on the way
(`window.lumabyte.onDock({ open, busy })`). A click calls `dock.toggle`.
