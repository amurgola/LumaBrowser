# IntegratedScenePrompt

`extensions/roleplay-mode/prompts/IntegratedScenePrompt.js`

The edit-model prompt that places one character into the saved scene for a
dynamic beat, with one reference image only.

## Methods

- `IntegratedScenePrompt.build(data, { char, emotion, directorShot })` -> `{ prompt, negativePrompt }`.
- `IntegratedScenePrompt.NEGATIVE`.
