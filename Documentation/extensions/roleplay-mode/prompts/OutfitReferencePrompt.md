# OutfitReferencePrompt

`extensions/roleplay-mode/prompts/OutfitReferencePrompt.js`

The edit-model prompt that redresses a character as a full-body chroma-plate
reference; the swap leads and closes the prompt.

## Methods

- `OutfitReferencePrompt.build(data, char, outfit, hasSourceRef)` joined with `, `.
- `OutfitReferencePrompt.NEGATIVE`.
