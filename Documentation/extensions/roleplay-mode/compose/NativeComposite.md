# NativeComposite

`extensions/roleplay-mode/compose/NativeComposite.js`

The nativeImage reaction composite, the fallback when the canvas path fails.

## Methods

- `NativeComposite.compose(sceneB64, charB64, width, height)` a PNG b64 or null.
  Tunable with `RP_COMP_H`, `RP_COMP_KEY`, `RP_COMP_ERODE`.
