# FigureKeyer

`extensions/roleplay-mode/compose/FigureKeyer.js`

Keys a character figure out of its render backdrop.

## Methods

- `FigureKeyer.key(b64, { thr, erode, globalKey, despill, greenDomMargin, globalThr, pocketMaxFrac })`
  -> `{ canvas, bbox, keyed, W, H }` (`keyed[p]` 1 = background).
