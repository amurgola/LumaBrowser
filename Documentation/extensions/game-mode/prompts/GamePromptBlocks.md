# GamePromptBlocks

`extensions/game-mode/prompts/GamePromptBlocks.js`

The fixed blocks of the Game system prompt: `GAME_PROJECT` (folder layout, classic scripts, `window.G`), `PHASER_GROUNDING` (real Phaser 3 API facts), `KNOWLEDGE` (the two KB corpora), `AI_RUNTIME` (the `window.AI` contract) and `NO_TOOL_WORKFLOW`.

## Text

Model-facing text is legacy's with em-dashes replaced by colons or semicolons; the scenes line reads "one class per scene. BootScene (...)".
