# GenerateAssetTool

`extensions/game-mode/tools/assets/GenerateAssetTool.js`

`generate_asset`: one image asset. The placeholder is written immediately; the real image is generated inline when [ImageCapability](../../assets/ImageCapability.md) allows, else queued for after the turn. The spec is prepared with the routed model and the game palette, so an RD Flow 64 sprite gets its own caption and 64x64 render.
