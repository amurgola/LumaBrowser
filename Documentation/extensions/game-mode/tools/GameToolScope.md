# GameToolScope

`extensions/game-mode/tools/GameToolScope.js`

What every Game tool of one turn shares: the extension context, the conversation, its game folder, the session map, the game name and kind.

## Methods

- `new GameToolScope({ context, conversationId, sessions, gameDir, name, kind })`; `code`, `chat`; `session()` ([GameSessions](../session/GameSessions.md)`.ensure`); `existingSession()`.
