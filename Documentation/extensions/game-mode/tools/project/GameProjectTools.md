# GameProjectTools

`extensions/game-mode/tools/project/GameProjectTools.js`

Builds the seven file tools of one turn and tallies every result's length into `session.served`, the quantity the whole-read guard ages against. The wrapper keeps every handler argument (the write tools need `opts.emit`).

## Methods

- `GameProjectTools.build({ context, conversationId, sessions, gameDir, name, kind, truncator, wholeFileMaxBytes, ctxPerSlot })`.
