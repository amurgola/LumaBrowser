# PhaserProbeReport

`extensions/game-mode/smoke/PhaserProbeReport.js`

Renders the Phaser probe: per game, active scenes with object counts by type, camera scroll/zoom/alpha and a lingering fade, per-object geometry (hidden, alpha, scroll factor, children), MISSING textures and up to 24 loaded textures.

## Methods

- `PhaserProbeReport.lines(games)`.
