# ExtIcons

`extensions/ui-kit/ui/ExtIcons.js`

Inline 12x12 SVG icons for extension renderers, drawn in `currentColor`.

## Members

- `ExtIcons.CHECK`, `ExtIcons.CARET`, `ExtIcons.MORE` (SVG markup strings).

`extensions/ui-kit/` is a plain shared folder, not an extension (no
`manifest.js`).

## Globals

None.
