# TimeText

`extensions/ui-kit/ui/TimeText.js`

Short time wording for extension list rows.

## Methods

- `TimeText.formatTime(iso)`: a locale stamp (short month, day, 2-digit hour and
  minute); `'never'` for none; an unparseable value is echoed back.
- `TimeText.formatRelative(iso)`: `'in 4 min'` or `'2 h ago'`, in s, min, h or d;
  `''` for none or unparseable.

## Globals

None.
