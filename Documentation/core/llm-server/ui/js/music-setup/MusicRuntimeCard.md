# MusicRuntimeCard

`core/llm-server/ui/js/music-setup/MusicRuntimeCard.js`

Paints the Music Runtime card (or the CUDA-only notice) and wires its buttons: install (shows "Preparing install…" at once), cancel, uninstall (confirm first), check for updates, stop server.
