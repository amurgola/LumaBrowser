# MusicDefaultsCard

`core/llm-server/ui/js/music-setup/MusicDefaultsCard.js`

The Music Defaults card: enable, default model, seed (blank = random), max song length (default 300 s) and idle unload. Any field change saves all of them; gated with a pointer at the missing step.
