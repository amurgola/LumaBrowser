# MusicModelsCard

`core/llm-server/ui/js/music-setup/MusicModelsCard.js`

The Music Models card: Download (disabled while another runs or without the server), progress with Cancel, or Installed with Delete (confirm first); an error stays on its row. Gated and greyed until the server exists.

## Methods

- `paint()`; `patchDownloadRow()`; `MusicModelsCard.progressText(dl)`.
