# ReadmeBlocks

`core/llm-server/ui/js/models/ReadmeBlocks.js`

The block pass of the README renderer: vaulted block lines, fenced code, GFM tables, headings, horizontal rules, block quotes, ordered and unordered lists, and paragraphs.

## Methods

- `new ReadmeBlocks(inline).render(source)` returns the joined block HTML (tokens still in place).

## Globals

None.
