# ImageRuntimeRow

`core/llm-server/ui/js/image-setup/ImageRuntimeRow.js`

Markup for one collapsible image runtime row: status badges ("ready" needs the hardware AND an installed binary or a prebuilt asset for this host), the primary Install or Update (hidden while installing, shown again after a failure), details with version, path and secondary actions, and the progress strip.

## Methods

- `ImageRuntimeRow.html(runtime, progress)`; `ImageRuntimeRow.badges(runtime)`.

## Globals

None.
