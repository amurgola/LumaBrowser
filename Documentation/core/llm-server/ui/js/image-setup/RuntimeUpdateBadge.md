# RuntimeUpdateBadge

`core/llm-server/ui/js/image-setup/RuntimeUpdateBadge.js`

`RuntimeUpdateBadge.apply(body, id, info)` applies a cached upstream-update result to one runtime row: the primary button reads "Update" with a version title, and an "update: vX" pill joins the head when a newer release exists.

## Globals

Reads `window.CSS.escape`.
