# InstalledModelRow

`core/llm-server/ui/js/image-setup/InstalledModelRow.js`

`InstalledModelRow.view(model, defaults, downloading)` builds the mlRow view of an installed image model: category pill ("generation + edit" for unified weights), default badges, file-update pills, NC and imported pills, and the actions Pin, Pin as edit default (unified only), Update <file>, Move to <other categories> (never Edit for a unified model), LoRAs / speed and Remove. All interpolated values are escaped.
