# RamPinHint

`core/llm-server/ui/js/image-setup/RamPinHint.js`

The caption on the image "RAM pin" row: pin progress, the pinned size, or the failure. Re-polls every 1.5 s while pinning or just after enabling.

## Methods

- `refresh()`; `RamPinHint.describe(status)` returns `{ text, poll }`.

## Globals

None (looks up `#imgRamPinHint`).
