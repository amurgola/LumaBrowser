# RuntimeProgressMarkup

`core/llm-server/ui/js/image-setup/RuntimeProgressMarkup.js`

The always-present progress strip of an image runtime row: an idle strip, a phase label with bytes and a bar (indeterminate while the total is unknown), or the failure line.

## Methods

- `RuntimeProgressMarkup.html(progress)`; `RuntimeProgressMarkup.label(phase, pct)`.

## Globals

None.
