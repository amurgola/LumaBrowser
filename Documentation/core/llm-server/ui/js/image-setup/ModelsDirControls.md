# ModelsDirControls

`core/llm-server/ui/js/image-setup/ModelsDirControls.js`

The image models-folder controls, mirroring the LLM "Models Directory" card: a path field that commits on change (Enter blurs), Browse, and "Use default" while a custom path is set. No Save button.

## Methods

- `ModelsDirControls.html(cfg)`; `new ModelsDirControls(body, api, onSaved).wire()`; `save(dir)` shows Saving…, Saved. or the error.

## Globals

None.
