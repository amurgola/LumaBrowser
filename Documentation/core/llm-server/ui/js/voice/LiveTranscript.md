# LiveTranscript

`core/llm-server/ui/js/voice/LiveTranscript.js`

The transcript strip pinned at the top of `.cm-composer-wrap` while the user
talks: a "You" bubble with a live dot during partials, the final text until it
is submitted.

## Methods

- `new LiveTranscript(getAnchor)`; `show(text, final)`; `hide()` (every strip in the document).
