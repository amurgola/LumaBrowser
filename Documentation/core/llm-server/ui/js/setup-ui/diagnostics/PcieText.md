# PcieText

`core/llm-server/ui/js/setup-ui/diagnostics/PcieText.js`

Describes a GPU's PCIe link: current and maximum generation and width, downtraining, and the theoretical one-direction bandwidth.

## Methods

- `PcieText.describe(pcie)`: `{ cur, max, downtrained, bw }` or null; `GB_PER_LANE` by generation.

## Globals

None.
