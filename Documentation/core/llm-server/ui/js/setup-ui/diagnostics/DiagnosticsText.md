# DiagnosticsText

`core/llm-server/ui/js/setup-ui/diagnostics/DiagnosticsText.js`

Text helpers of the Server Info cards.

## Methods

- `mb(n)`: megabytes on the app byte ladder (`n/a` for junk); `pct(used, total)`; `usageBadgeClass(ratio)`: ok under 70%, warn under 90%, else bad.

## Globals

None.
