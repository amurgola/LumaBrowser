# BudgetCard

`core/llm-server/ui/js/setup-ui/diagnostics/BudgetCard.js`

The Server Info "Model budget" card: the RAM and VRAM the launch planner may spend after reserves, per adapter, with an explanation when no adapter reports VRAM.

## Methods

- `BudgetCard.render(doc, budget)`; `BudgetCard.pillText(ram, vram)`.

## Globals

Reads `document` by id.
