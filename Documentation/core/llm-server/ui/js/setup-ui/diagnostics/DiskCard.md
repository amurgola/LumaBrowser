# DiskCard

`core/llm-server/ui/js/setup-ui/diagnostics/DiskCard.js`

The Server Info "Disks" card: each volume's free space, filesystem and a usage badge coloured by DiagnosticsText.

## Methods

- `DiskCard.render(doc, data)` paints the card's pill and body by their fixed ids.

## Globals

Reads `document` by id.
