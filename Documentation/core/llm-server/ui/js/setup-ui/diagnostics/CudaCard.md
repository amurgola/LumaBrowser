# CudaCard

`core/llm-server/ui/js/setup-ui/diagnostics/CudaCard.js`

The Server Info "CUDA" card: the CUDA version and each NVIDIA device from nvidia-smi, or why CUDA was not detected, with the nvidia-smi PATH hint.

## Methods

- `CudaCard.render(doc, data)` paints the card's pill and body by their fixed ids.

## Globals

Reads `document` by id.
