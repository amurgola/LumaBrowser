# DiagnosticsPainter

`core/llm-server/ui/js/setup-ui/diagnostics/DiagnosticsPainter.js`

Paints one diagnostics payload into every Server Info card and the header's host line.

## Methods

- `paint(doc, d)`; `hostLine(platform)`: `<os> <arch> · kernel <release> · <hostname>`.

## Globals

Reads `document` by id.
