# RuntimeRowHtml

`core/llm-server/ui/js/setup-ui/runtimes/RuntimeRowHtml.js`

One collapsible runtime row: status badges, the primary Install/Update button that stays visible collapsed, and the details panel with version, path, provenance and the secondary actions.

## Methods

- `html(r)`; `statusLabel(r)`; `badges(r)`; `secondaryActions(r)` (Uninstall for managed, Clear registration for manual, Relocate when installed, Download pre-release for GitHub-release runtimes with an asset, then Build instructions or See releases).

## Globals

None.
