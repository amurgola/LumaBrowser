# RuntimeProvenanceHtml

`core/llm-server/ui/js/setup-ui/runtimes/RuntimeProvenanceHtml.js`

A runtime row's provenance lines: the upstream project and acquisition, and for a managed install the exact release asset (name, size, companions, tag, SHA-256).

- `html(r)`: `''` for a format row or no repo; `sourceLink(url, label)`; `ACQUISITION_LABELS`.
