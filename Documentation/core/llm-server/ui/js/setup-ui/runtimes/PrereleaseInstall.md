# PrereleaseInstall

`core/llm-server/ui/js/setup-ui/runtimes/PrereleaseInstall.js`

The "Download pre-release" action: resolves the newest upstream build first so the confirmation names the exact tag, then installs it over the managed copy.

## Methods

- `run(id)`; `confirmText(current, candidate)`.

## Globals

Dialogs through [Dialogs](../../dialogs/Dialogs.md) (themed LumaModal when loaded).
