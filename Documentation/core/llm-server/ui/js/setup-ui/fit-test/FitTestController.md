# FitTestController

`core/llm-server/ui/js/setup-ui/fit-test/FitTestController.js`

Runs the measured fit test from a model row: start, cancel, events, rehydration, and pinning a measured row as the Start defaults.

## Methods

- Fields `state`, `view`; `bindEvents()`, `refresh()` (patches every row's fit block), `start(path)`, `cancel()`, `use(path, ctx, kv)`, `hydrate()`.

## Globals

None.
