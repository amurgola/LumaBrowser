# FitTestView

`core/llm-server/ui/js/setup-ui/fit-test/FitTestView.js`

The fit-test block on a model row: the run, re-run or cancel control, notes, and the measured table whose "Use" buttons pin a combination as the Start defaults.

## Methods

- `key(path)` (stable id hash), `blockHtml(path)`, `contentHtml(path)`, `tableHtml(path, st)`; columns follow the KV modes the run measured.

## Globals

None.
