# ModelRename

`core/llm-server/ui/js/setup-ui/models/ModelRename.js`

The per-model display-name override: the pencil swaps a row head for an input with Save and Cancel.

## Methods

- `handleClick(target)` (true when it was a rename control), `begin(pencil)`, `save(button)` (blank means automatic; the list re-renders either way), `handleEnter(target, event)`, `editorHtml(key, current)`.

## Globals

None.
