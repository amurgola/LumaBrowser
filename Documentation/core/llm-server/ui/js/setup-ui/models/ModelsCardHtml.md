# ModelsCardHtml

`core/llm-server/ui/js/setup-ui/models/ModelsCardHtml.js`

The fixed markup of the Models Directory card: the list scaffold, the directory controls, the empty or unavailable note and the "Where models come from" callout.

## Methods

- `scaffold()`, `controls(config)`, `listNote(scan)`, `bottom(scan)`, `pillText(scan)`, `installedMeta(total, current)`, `sourceCallout()`.

## Globals

None (FoldMemory reads `localStorage`).
