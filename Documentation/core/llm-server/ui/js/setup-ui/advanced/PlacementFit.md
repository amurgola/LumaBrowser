# PlacementFit

`core/llm-server/ui/js/setup-ui/advanced/PlacementFit.js`

Measured-fit arithmetic of the placement canvas: what each item, singularity and lane commits according to the last test render.

## Methods

- `itemBytes(key)` (an LLM with its context in RAM counts its weights), `singularityMax(s)`, `lanePlanned(resId)`, `capacity(resource)`.

## Globals

None.
