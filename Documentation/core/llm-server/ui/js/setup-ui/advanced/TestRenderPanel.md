# TestRenderPanel

`core/llm-server/ui/js/setup-ui/advanced/TestRenderPanel.js`

The "Test render" panel: runs the cat-and-hat test, streams its status, and shows each step plus where each model ran and its peak VRAM and RAM. The run records the footprints that unlock allocation.

## Methods

- `render(body)`, `run(panel)`, `statusText(event)`.

## Globals

None.
