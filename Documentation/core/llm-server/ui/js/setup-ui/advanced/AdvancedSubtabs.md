# AdvancedSubtabs

`core/llm-server/ui/js/setup-ui/advanced/AdvancedSubtabs.js`

The Advanced view's sub-tab strip (Model Placement, Server Info, Data): toggles panes and retitles the page header.

## Methods

- `wire(onWired)` (once; marks the strip `data-wired`), `apply(name)`, field `current`.

## Globals

Reads `document` (`#advancedRoot`, `#advSubtabs`, `#pageTitle`).
