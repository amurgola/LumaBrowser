# PlacementChips

`core/llm-server/ui/js/setup-ui/advanced/PlacementChips.js`

Builds the model chips (and the split-out context chip) and drops each where the layout puts it.

## Methods

- `distribute(root, tray)`, `chip(item)` (the split affordance only for a measured LLM on a local GPU or group outside a singularity), `contextChip()`, `PlacementChips.container(root, target)`.

## Globals

None.
