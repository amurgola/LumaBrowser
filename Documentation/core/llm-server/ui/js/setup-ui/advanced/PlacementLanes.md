# PlacementLanes

`core/llm-server/ui/js/setup-ui/advanced/PlacementLanes.js`

Builds the drop lanes: local GPUs, ordered groups, remote peer GPUs (including unpaired refs, marked unavailable) and System RAM, each with its plan bar and singularity boxes.

## Methods

- `build()`, `gpuLane(d)`, `remoteLane(rd)`, `groupLane(r)`, `ramLane()`, `planBar(resId, resource)`.

## Globals

None.
