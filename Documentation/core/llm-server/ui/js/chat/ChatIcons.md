# ChatIcons

`core/llm-server/ui/js/chat/ChatIcons.js`

The chat's inline SVG icons (stroke `currentColor`) as static strings, plus the
LumaBrowser app mark (`logo`) and `pulse()`, the pulsing logo painted into a
reply before its first token.

## Methods

- Static strings: `plus`, `search`, `panel`, `sliders`, `chevron`, `dots`,
  `copy`, `retry`, `readAloud`, `readStop`, `check`, `send`, `stop`, `edit`,
  `trash`, `pin`, `tools`, `doc`, `image`, `expand`, `paperclip`, `gear`, `x`,
  `clock`, `play`, `pause`, `download`, `link`, `share`, `grid`, `book` (the
  documentation source pill), `mic`, `logo`.
- `ChatIcons.pulse()`.
