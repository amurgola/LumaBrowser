# TriggerText

`core/llm-server/ui/js/chat/tasks/TriggerText.js`

Trigger texts: sidebar suffixes that keep an unarmed trigger from looking live,
status labels, webhook URLs per base, the curl example (quoting the sample body),
pretty events, and delivery-outcome labels and dot colours.

## Methods

- `TriggerText.suffix(t)`, `statusLabel(t)`, `urls(t, baseUrls)`,
  `curl(url, sample)`, `prettyEvent(event)`, `deliveryLabel(outcome)`,
  `deliveryDot(outcome)`, `DELIVERY_DOT`, `DELIVERY_LABEL`.
