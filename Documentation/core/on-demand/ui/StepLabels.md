# StepLabels

`core/on-demand/ui/StepLabels.js`

Plain-language labels for the agent's page actions.

## Methods

- `StepLabels.label(tool, params)`: `VERBS[tool]`, else "Using <tool with spaces>".
- `StepLabels.short(s, n = 40)`, `StepLabels.target(p)` (`[ref]`, quoted text, or
  a 30-character selector).
