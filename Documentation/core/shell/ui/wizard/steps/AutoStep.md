# AutoStep

`core/shell/ui/wizard/steps/AutoStep.js` (ES module)

The Automatic Local Setup step: a title per view and the pane for it.

## Methods

- `render()`: titles "Do you also want image generation?", "Do you also want
  music generation?", "Your setup", "Setting everything up", "All set", else
  "Something went wrong"; an unknown view shows that title over the image
  question pane.
- `pane()` (`#setupAutoPane`); `runner` ([AutoRunner](../auto/AutoRunner.md)).

## Globals

None.
