# ExtensionConfigHeader

`core/shell/ui/settings/ExtensionConfigHeader.js` (ES module)

The header above an extension's configuration: Back, title and description, Export .zip and Edit code, and "Depends on".

## Methods

- `ExtensionConfigHeader.build({ titleHtml, description?, dependencies }, { onBack, onEdit, onExport })`
  returns the `.ext-config-header` element. `titleHtml` is already escaped.

## Globals

None.
