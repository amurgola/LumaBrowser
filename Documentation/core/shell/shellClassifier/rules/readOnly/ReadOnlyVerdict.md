# ReadOnlyVerdict

`core/shell/shellClassifier/rules/readOnly/ReadOnlyVerdict.js`

Frozen answer `{ readOnly, reason }` from a read-only profile.

## Methods

- `ReadOnlyVerdict.reads(reason)` and `ReadOnlyVerdict.refuses(reason)`.

## Why

Every profile explains itself, so `ReadOnlyRule.explain` and the tests can show which option or form decided.
