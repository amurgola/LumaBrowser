# GeneratedFileWriter

`tools/ide/GeneratedFileWriter.js`

Writes generated files stamped with a do-not-edit note, only when the content changed.

## Methods

- `GeneratedFileWriter.syncFiles(root, destDir, pairs, by)`, `GeneratedFileWriter.stamp(name, text, note)`,
  `GeneratedFileWriter.write(dst, body)` (true when written).
