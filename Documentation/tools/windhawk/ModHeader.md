# ModHeader

`tools/windhawk/ModHeader.js`

A re-export of [WindhawkModSource](../../core/shell/windhawk/WindhawkModSource.md),
which lives in core because the app's Windhawk installer reads mods the same
way. [WindhawkModChecker](WindhawkModChecker.md) uses `parse`, `targets`,
`splitArgs` and `clientBlock`.
