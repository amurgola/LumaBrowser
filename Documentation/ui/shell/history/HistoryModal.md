# HistoryModal

`ui/shell/history/HistoryModal.js`

The History view: searchable day-grouped list, row delete, Clear for last hour / today / all time, and Clear cache.

## Methods

- `install()`, `isOpen()`, `open()`, `close()`, `toggle()`, `refresh()`, `render(search)`, `clearRange()`.
- `HistoryModal.rangeFor(mode, now)`.

## Globals

Reads `window.historyAPI`.
