# BookmarkEditBar

`ui/shell/bookmarks/BookmarkEditBar.js`

The in-flow edit bar under the toolbar: rename, move between the bar and top-level folders, remove; Enter saves, Escape closes.

## Methods

- `install()`, `isOpen()`, `open(node, tab, added)`, `close()`, `save()`, `remove()`.

## Globals

Reads `window.bookmarksAPI`.
