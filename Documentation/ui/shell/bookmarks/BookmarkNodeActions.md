# BookmarkNodeActions

`ui/shell/bookmarks/BookmarkNodeActions.js`

Rename, edit URL, toggle open-on-startup, delete (themed confirm) and new folder, shared by the bar menu and the manager.

## Methods

- `rename(node)`, `editUrl(node)`, `toggleStartup(node)`, `remove(node)`, `addFolder()`.

## Globals

Reads `window.bookmarksAPI`; dialogs through Dialogs (`window.LumaModal`).
