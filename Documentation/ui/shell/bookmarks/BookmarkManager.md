# BookmarkManager

`ui/shell/bookmarks/BookmarkManager.js`

The bookmark manager modal: tree with rename, delete, move-to-folder and open-on-startup per bookmark, plus New folder.

## Methods

- `install()`, `isOpen()`, `open()`, `close()`, `render()`, `folderOptions(parentId)`.

## Globals

Reads `window.bookmarksAPI`.
