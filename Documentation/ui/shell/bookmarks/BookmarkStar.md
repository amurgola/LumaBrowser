# BookmarkStar

`ui/shell/bookmarks/BookmarkStar.js`

The address-bar star (and Ctrl+D): filled when the page is bookmarked; a click bookmarks if needed and opens the edit bar (a second click closes it).

## Methods

- `install()`, `refresh(url)`, `clicked()`, `btn`.
- `BookmarkStar.isWebUrl(url)`.

## Globals

Reads `window.bookmarksAPI`.
