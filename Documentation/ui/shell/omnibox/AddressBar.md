# AddressBar

`ui/shell/omnibox/AddressBar.js`

The address input: shows the active URL (not while the user edits), reverts, focuses with select-all, carries the placeholder and the popup anchor rect.

## Methods

- `el`, `isFocused()`, `showUrl(url)`, `showUrlUnlessEditing(url)`, `revert()`, `focusAndSelect()`, `setPlaceholder(text)`, `anchorRect()`.

## Globals

None.
