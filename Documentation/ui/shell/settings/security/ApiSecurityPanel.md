# ApiSecurityPanel

`ui/shell/settings/security/ApiSecurityPanel.js`

API Security: network mode, IP whitelist (with inline errors) and the require-key switch; reloads on open and masks keys on close.

## Methods

- `install()`, `load()`, `state`.
- `ApiSecurityPanel.normalise(cfg)`.

## Globals

Reads `window.electronAPI.apiSecurity`.
