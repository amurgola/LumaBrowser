# ApiMcpGroups

`ui/shell/settings/general/ApiMcpGroups.js`

Builds the API & MCP cards from the endpoint catalog (prefixed `api:` / `mcp:` names, core first) and splits the off set back into deny-lists.

## Methods

- `build(data, activeExtIds, extNames)`, `disabled(groups, on)`, `sourceLabel(source, extNames)`, `visible(source, activeExtIds)` (static).

## Globals

None.
