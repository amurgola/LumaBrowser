# TerminalSettingsRows

`ui/shell/settings/general/TerminalSettingsRows.js`

The built-in terminal's rows in Settings > Editors & agents > Terminal: **Default terminal** (`#gsTerminalProfile`,
shells only: an app profile runs inside the default shell) and **Let AI use the terminal** (`#gsTerminalAgent`, off
until the user turns it on). Both autosave through `core.terminal.setSettings`.

## Methods

- `new TerminalSettingsRows({ feedback })`, `install()`, `load()`.
