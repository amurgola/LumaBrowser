# SettingsMenu

`ui/shell/settings/SettingsMenu.js`

The gear dropdown in the overlay (its own 'settings-menu' mode, so window blur never drops a click): new tab, history, bookmarks, downloads, find, print, zoom, clearing data, Settings, Extensions, About, Exit.

## Methods

- `install()`, `show()`, `items()`, `open`.

## Globals

Reads `window.tabAPI.print`, `window.windowAPI.close`.
