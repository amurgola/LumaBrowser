# TabContextMenu

`ui/shell/tabs/TabContextMenu.js`

The tab right-click menu: reload, duplicate, copy URL, mute, zoom, persist, extension items, close / close others / close to the right (never the pinned tab).

## Methods

- `show(x, y, tabId)`.
- `build(tab, tabId)` -> `{ items, map }`.

## Globals

Reads `window.tabAPI`.
