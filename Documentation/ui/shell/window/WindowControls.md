# WindowControls

`ui/shell/window/WindowControls.js`

Wires the frameless title bar buttons to `windowAPI` and mirrors the maximized state onto the maximize button (sprite icon `i-win-max` or `i-win-restore`, Windows 11 caption style, plus a Maximize/Restore label) and `body.window-maximized`.

## Methods

- `install()`.

## Globals

Reads `window.windowAPI`.
