# FindBar

`ui/shell/find/FindBar.js`

Find in page: an in-flow bar beneath the toolbar driving `findInPage` for regular web tabs, with match count, next/previous and Escape.

## Methods

- `install()`, `isOpen()`, `open()`, `close(clearSelection)`, `step(forward)`, `run(text, opts)`, `setCount(res)`.
- `FindBar.supported()`.

## Globals

Reads `window.tabAPI` find methods.
